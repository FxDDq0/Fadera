First public release of **Mixora** for Windows x64: a desktop controller for Behringer X32 / Midas M32 family digital mixers.

> Mixora is an independent project, not affiliated with Behringer, Midas or Music Tribe.

### Downloads

| File | Use |
|---|---|
| `Mixora-1.0.0-setup.exe` | Installer (recommended). Installs for the current user, no administrator rights needed. |
| `Mixora-1.0.0-windows-x64.zip` | Portable version: extract and run `Mixora.exe`. |
| `*.sha256` | SHA-256 checksums: `Get-FileHash <file> -Algorithm SHA256` |

The files are **not digitally signed**: Windows SmartScreen may warn on first run. Compare the SHA-256 before choosing *Run anyway*.

### Compatibility

Verified on a **Behringer X32 Producer, firmware 4.15** for the essential functions (connection, sync, faders, mute, solo, pan, channel processing, EQ, dynamics, sends, DCA, meters, reconnection). Other models and some advanced features are not yet verified: see [COMPATIBILITY.md](../COMPATIBILITY.md) and [KNOWN_LIMITATIONS.md](../KNOWN_LIMITATIONS.md).

### Requirements

Windows 10/11 x64, PC on the same network as the mixer. No Internet access and no other software needed.

### Languages

English, Italiano, Español, Français, Deutsch, Português. The language follows Windows automatically and can be changed in *Settings → General*.
